# sf-logout [<img align="right" src="https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png" width="18" alt="GitHub repository" />](https://github.com/navikt/sf-logout)

En Kotlin-tjeneste som inngår i utloggingsflyten mellom NAV og Salesforce. Tjenesten videresender utloggingsforespørsler til Salesforce med en tjenestebruker, slik at utlogging kan håndteres på tvers av systemene.
